# Life-and-Annuity-for-NC

Study site for the North Carolina Life & Annuity license exam, built from personal study notes.

**Live site:** https://rafikiscyent888.github.io/Life-and-Annuity-for-NC/

| File | What it is |
| --- | --- |
| `index.html` | Home page with tiles for the study guide and the practice test |
| `study-guide.html` | Eleven-topic study guide, numbers to memorize and memory aids |
| `practice-test.html` | 150-question practice test (131 multiple choice, 13 true/false, 6 short answer) with instant feedback |
| `styles.css` | Shared rainbow colors, fonts and layout for all pages |

The practice test has seven parts, one per rainbow color (A red through G violet). Each study guide topic uses the color of the test part that covers it. Quiz progress is saved in the visitor's browser only.

The **retake test** (`practice-test.html#retake`) runs through only the questions you've missed. Answering one right takes it off the missed list. At the end, a results page groups whatever is still missed by study guide topic, with links to study each one and a button to retake the rest. The home page shows a reminder whenever there are missed questions.

Items marked **Verify** in the study guide come only from the source notes. Confirm North Carolina deadlines and dollar amounts against your course materials.

Questions 1–100 come from the study notes. Questions 101–150 cover topics from the [NC Department of Insurance exam content outline](https://www.ncdoi.gov/documents/company-licensing/nc-insurance-licensing-examination-candidate-guide/open) (effective March 15, 2024) and are checked against the NC General Statutes and federal rules; each links to its source.
