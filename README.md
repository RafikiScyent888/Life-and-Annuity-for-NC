# Life-and-Annuity-for-NC

Study site for the North Carolina Life & Annuity license exam, built from personal study notes.

**Live site:** https://rafikiscyent888.github.io/Life-and-Annuity-for-NC/

| File | What it is |
| --- | --- |
| `index.html` | Home page with tiles for the study guide and the practice test |
| `study-guide.html` | Ten-topic study guide, numbers to memorize and memory aids |
| `practice-test.html` | 100-question practice test (85 multiple choice, 10 true/false, 5 short answer) with instant feedback |
| `styles.css` | Shared rainbow colors, fonts and layout for all pages |

The practice test has seven parts, one per rainbow color (A red through G violet). Each study guide topic uses the color of the test part that covers it. Quiz progress is saved in the visitor's browser only.

Items marked **Verify** in the study guide come only from the source notes. Confirm North Carolina deadlines and dollar amounts against your course materials.
